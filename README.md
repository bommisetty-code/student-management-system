# Student Management System

A simple Python-based Student Management System that allows users to manage student records using a command-line interface.

## Features

- Add Student
- View All Students
- Search Student
- Update Student
- Delete Student
- View Student Result
- Grade Calculation
- Pass/Fail Result
- Input Validation
- Duplicate Student ID Validation
- JSON File Storage
- Exception Handling

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
- JSON
- File Handling
- Exception Handling
